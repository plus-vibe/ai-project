# SmartWallet AI — Предиктивный финансовый коуч
Персональный ИИ-помощник, который не просто считает твои траты, а помогает менять финансовые привычки и достигать целей.


# Проблема
Большинство приложений для учёта расходов:
- Показывают цифры постфактум ("ты потратил 5000₽ на кофе")
- Требуют ручного ввода каждой траты
- Не помогают изменить поведение
- Не дают персонализированных рекомендаций
Результат: Пользователь видит проблему, но не знает, что с ней делать.

# Решение
SmartWallet AI — это Telegram-бот с искусственным интеллектом, который:
- Автоматически распознаёт траты из текста, фото чеков или уведомлений банка
- Анализирует паттерны поведения с помощью SQL-аналитики
- Предсказывает срывы и предупреждает заранее
- Даёт персонализированные рекомендации на основе твоих данных
- Помогает достигать финансовых целей через ежедневные лимиты



# Killer Features
1. Предиктивные предупреждения

Бот анализирует твои паттерны и заранее предупреждает о рисках:

"Завтра пятница. В последние 3 пятницы ты тратил в среднем 3500₽ на развлечения. Давай установим лимит 1500₽?"

**Технология**: SQL с оконными функциями (LAG, AVG() OVER) для анализа скользящих паттернов.

2. Обнаружение "слепых зон"
Находит категории трат, которые ты не замечаешь:

"У тебя 7 активных подписок на 2500₽/мес. 3 из них ты не открывал больше месяца. Отменить?"

**Технология**: Поиск повторяющихся платежей + классификация через LLM.

3. Режим цели

Устанавливаешь цель (например, "1 млн ₽ за 2 года"), и бот рассчитывает:
    - Сколько откладывать в месяц
    - Какой дневной лимит трат
    - В реальном времени показывает: "Сегодня можешь потратить 1200₽, чтобы не сбиться с графика"

4. What-If симулятор

Спрашиваешь: "Если я буду тратить на кофе на 50% меньше, сколько сэкономлю за год?"

Бот отвечает: "Сэкономишь 36 400₽. Это 2 поездки в Турцию."

**Технология**: SQL-аналитика + эмоциональная подача через LLM.




# Целевая аудитория
Основные пользователи:
- Молодые специалисты (22-35 лет), которые хотят контролировать финансы, но не хотят тратить время на сложные приложения
- Люди с финансовыми целями (накопить на квартиру, машину, путешествие)
- Те, кто устал от импульсивных трат и хочет изменить привычки

Дополнительные сегменты:
- Фрилансеры с нерегулярным доходом
- Студенты, обучающиеся финансовой грамотности
- Родители, планирующие семейный бюджет

# Технический стек
- Frontend: Telegram Bot (Python + aiogram)
- Backend: Python 3.11+
- Database: PostgreSQL + pgvector (для будущих ML-фич)
- AI/ML: LLM API (YandexGPT / OpenAI / локальные модели)
- DevOps: Docker, Docker Compose
- Analytics: SQL с оконными функциями
